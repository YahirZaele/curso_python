# Curso de Python 🐍

Repositorio con apuntes, ejercicios prácticos y proyectos desarrollados durante el curso de aprendizaje de Python.

---

## 📁 Estructura del Proyecto

- **`Class1.py`**: Introducción a comentarios, salida por consola e inspección de tipos de datos básicos (`type()`).
- **`ruleta.py`**: Mini-juego interactivo en terminal de ruleta de letras con animación y desaceleración progresiva.
- **`Excercisce C1/`**: Colección de ejercicios y fundamentos:
  - `HolaMundo.py`: Primeros pasos con `print()`.
  - `Variables.py`: Declaración y uso de variables.
  - `02_operators_excersies.py`: Operadores aritméticos, comparativos y lógicos.
  - `03_strings_exercises.py`: Manejo y manipulación de cadenas de texto.
  - `04_lists_exercises.py`: Operaciones y métodos con listas.
  - `05_tuples_exercises.py`: Ejercicios con tuplas y sus propiedades.
  - `06_sets_exercises.py`: Manejo de conjuntos (sets) y operaciones de conjuntos.

---

## 🚀 Cómo Ejecutar los Archivos

Asegúrate de tener Python instalado (versión 3.8 o superior recomendada).

### Ejecutar un ejercicio:
```bash
python "Excercisce C1/04_lists_exercises.py"
```

### Probar el juego de la ruleta:
```bash
python ruleta.py
```
